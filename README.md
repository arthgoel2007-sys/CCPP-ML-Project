# ⚡ CCPP Power Output Prediction

A Machine Learning project that predicts the electrical power output of a Combined Cycle Power Plant (CCPP) using environmental and operational parameters.

The project explores multiple regression algorithms, performs hyperparameter optimization, evaluates model performance, and deploys the final tuned model through an interactive Streamlit web application.

---

## 📌 Project Overview

Combined Cycle Power Plants generate electricity using a combination of gas and steam turbines. Their electrical power output depends on several environmental and operational conditions.

The objective of this project is to develop a Machine Learning model capable of accurately predicting electrical power output based on four input parameters:

- Ambient Temperature (AT)
- Ambient Pressure (AP)
- Exhaust Vacuum (V)
- Relative Humidity (RH)

The project follows an end-to-end Machine Learning workflow, from exploratory data analysis and model development to optimization, deployment, and containerization.

## 🤖 Machine Learning Models

Multiple regression algorithms were implemented and compared.

### Models Implemented

1. **Linear Regression**
   - Used as a baseline regression model.
   - Establishes a benchmark for predictive performance.

2. **Random Forest Regression**
   - Uses an ensemble of decision trees.
   - Captures nonlinear relationships between input variables and power output.

3. **Gradient Boosting Regression**
   - Builds an ensemble of sequentially trained decision trees.
   - Attempts to improve prediction accuracy by learning from previous errors.

4. **Tuned Random Forest Regression**
   - Hyperparameters optimized using GridSearchCV.
   - Uses 5-fold cross-validation.
   - Selected as the final prediction model.

### Hyperparameter Optimization

GridSearchCV was used to identify an effective combination of Random Forest hyperparameters.

The optimization process involved:

- Defining a parameter grid.
- Evaluating candidate configurations using 5-fold cross-validation.
- Using negative Root Mean Squared Error as the scoring metric.
- Selecting the best-performing estimator.

---

## 📈 Model Evaluation

Models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Coefficient of Determination (R² Score)

### Final Model Performance

The tuned Random Forest achieved the following results on the test dataset:

| Metric | Value |
|---|---:|
| MAE | 2.41 MW |
| RMSE | 3.44 MW |
| R² Score | 0.9598 |

An R² score of 0.9598 indicates that the model explains approximately 95.98% of the variance in the test dataset's electrical power output.

### Model Comparison

The following table compares the training and testing RMSE of the implemented models.

| Model | Training RMSE | Testing RMSE |
|---|---:|---:|
| Linear Regression | 4.55 | 4.59 |
| Random Forest | 1.24 | 3.45 |
| Gradient Boosting | 3.67 | 3.98 |
| Tuned Random Forest | 1.24 | 3.44 |

The tuned Random Forest achieved the lowest testing RMSE among the evaluated models.

The training-testing error comparison was also used to investigate overfitting.

## 🐳 Docker Containerization

The application is containerized using Docker to provide a consistent execution environment.

A Dockerfile defines the application environment, installs the required dependencies, copies the application files and model artifacts, and configures Streamlit.

### Run Docker Container


## 🚀 Running the Project Locally


```bash

```


## 📦 Model Persistence

The final tuned Random Forest model is serialized using Joblib and stored in:

```text
models/ccpp_model.joblib
```

Model evaluation metrics are stored separately in:

```text
models/model_metrics.json
```

This allows the deployed application to load the trained model directly without requiring model training every time the application starts.
